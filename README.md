A program that writes one absurd terms-of-service clause into `/output/entry.txt`.

## How to run

Requires Node 22 or newer. No dependencies, no network access.

```sh
node main.ts
```

The program writes a single sentence (152 characters, no trailing newline) to `/output/entry.txt`.

## The clause

> You agree that blinking more than ten times per minute constitutes excessive use; each excess blink incurs a $0.02 surcharge, billed monthly in arrears.

Blink too much and you owe us two cents per blink — billed monthly, in arrears, of course.
